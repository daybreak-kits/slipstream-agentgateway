# W4-C 模型域重构（ADR-025/026 UI 落地）

规范依据：ADR-025（可用性归属上游模型、公开模型仅启停）、ADR-026 词表、DESIGN-AUDIT §14-16、GLOSSARY §3。

> **历史计划记录（W4-C，2026-11-20）**；五期已把「公开模型整页两 Tab + 双栏成员 + 保存成员整批替换（PUT）」收敛为：单页三段（页头/基本信息/成员编排）+ 唯一「保存」+ 成员 chip（ticket 13/14），保存走 `PATCH /admin/public-models/{id}` 单事务（旧 `PUT .../targets` 删除）。冷却入口也收敛为行内单按钮双模式（单次/周期，互斥 409——ADR-027）。

## 范围

1. **冷却双模式弹窗（上游模型）**：models.tsx 的「冷却」「周期」两个入口合并为一个「冷却」按钮，弹窗内 Tab 切换：
   - 「单次冷却」：预设 1/3/6/12/24/72 小时（点选即时显示到期时刻，按运营时区），保留可选自定义时长与原因备注（现 cooldown-dialog 语义）。
   - 「周期冷却」：沿用现有紧凑编辑（重复方式+时间窗+IANA 时区，即现周期规则编辑）。
   - 冷却中打开时显示当前状态与「解除冷却」。公开模型表/弹窗的 冷却/周期 入口**全部移除**（ADR-025）。
2. **公开模型编辑+成员合并整页编辑器**：公开模型行内「编辑」「成员」合并为一个「编辑」入口，进入整页编辑器（新路由 `/models/public/:id`，列表行点击也可进；新建仍弹窗简化版）：
   - Tab1 基本与策略：名称/备注/路由策略（failover/weighted/conditional 现字段）。
   - Tab2 成员编排（双栏，用户定案）：左=现有成员列表（行内可调 priority/weight/when 条件，删除按钮移除，排序即优先级）；右=全部可选上游模型（搜索框过滤、点击即加入左侧，已加入的在右侧高亮、再点或点其删除标移除）；底部「保存成员」整批替换提交（现有 PUT 语义不变）。
3. **上游模型编辑器三处归一**：components/upstreams/models-panel.tsx 的编辑器改为复用 models.tsx 的编辑弹窗组件（字段全集：类型/类型来源/能力参数/入出倍率/启用），删除其字段缩减版；补齐 canWrite 门禁（与 models.tsx 同规则）；价目页行内编辑（upstream-prices 行内 drafts）不并入（保留，属价目域）。
4. **价格单元格**：`costText` 改 2 位小数（`¥2.00/M`、倍率 `×1.20`）；数值 <0.01 时自动升精度至 4 位（避免 ¥0.00）；未配价行主行显示灰字「未设置」（替代 入 -- · 出 --，样式同参数列「未声明」）；**日志明细 fmtMoney6 六位不动**。
5. 成员编排、批量按钮沿用 A1 图标映射；不碰 availability 后端 API（ADR-025 仅 UI 收敛）。

## 明确不做
不动 routing_mode 后端校验；不动上游密钥面板（D 波）；不动价目页。
