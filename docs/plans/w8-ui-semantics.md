# W8 UI 语义与交互修复计划

状态：已确认，待排期。基线 main 377d146。来源：m10077、m10188、m10193 grilling。

## 全局决策
- 端口显示统一走 host/port 语义：http 默认 80、https 默认 443 不显示端口；其他端口显示。0/空表示未启用，不伪造 3600。
- 时间区间统一完整格式 YYYY/MM/DD HH:mm:ss - YYYY/MM/DD HH:mm:ss；dirty 用值比较，不用引用比较。
- 表格统一固定布局：操作列最后且 sticky right；结果列固定两行槽位；按钮固定宽度；行高不随内容变化。
- dirty 标记统一使用现有 DirtyField 零位移效果；计数徽标固定槽，不进入文档流。
- 所有空值/未启用状态必须有显式语义，不显示 0、- 冒充正常值。

## 01 端口与 URL 显示
- 新增统一 authority/port 格式化函数，调用网关、运营设置、连接密钥、快速上手共用。
- data_plane_port <= 0：显示“未启用（外部数据面）”，不拼 :0。
- http:80 / https:443 省略端口；其他端口显示 :port。
- 运营设置“固定 3600”文案与 ADR-029 冲突，改为“数据面默认监听端口由适配器契约提供，未启用时不显示”。

## 02 日志时间选择器
- timeWindowKey 改为稳定可比较值（字符串或规范化数组）；dirty 用值比较。
- 触发按钮显示完整区间；预设也显示区间，避免只知道“近 24 小时”不知道边界。
- 仅当 draft 与 applied 不相等时黄边；非法态保持红色独立提示。

## 03 源密钥测试与表格行高
- 行内测试改为单把：每行测试只测当前 key；多选时出现“批量测试”。
- 后端支持 key_id 或 keys[] 参数；批量与单把复用同一探测函数。
- 结果列固定两行高；未测试也占两行；按钮固定宽；表格 fixed layout，列宽稳定。
- 路由与模型表同原语修复。

## 04 变换规则编辑
- 操作显示名中文化：创建字段、更新字段、删除字段、复制字段、头部添加、尾部添加、正则替换、全部大写、全部小写；wire 值不变。
- 空规则行忽略：不参与预览/保存校验；只校验非空行。前端补 conditions 校验（field 非空、mode 合法），逐条标错。
- 可视化/JSON 切换按钮放“保存全部”旁；共用同一规则模型，切换不丢数据；JSON 保存前做 schema、必填、条件、空字段校验。
- 试运行拆成“预览规则”（编译并显示最终 transformations）与“样例测试”（粘贴请求/响应头体，展示修改前后字段 diff）。

## 05 模型管理
- 上游模型保留思考档位能力声明，删除默认思考档选择器；默认档归公开模型/模型试验。
- 分组标题的 N 项未保存 Badge 改固定槽/绝对定位，保证抽屉高度零变化。
- 公开模型策略列只留 Badge，长解释进 HoverInfo。

## 06 价目管理
- 列设置旁加“表格 / JSON”切换；JSON 直接在当前页编辑，保存复用现有导入端点与全批确认。
- JSON 校验：schema_version、未知字段、必填字段、类型、空值、重复行；错误逐行展示且不落库。
- 操作列常驻编辑；支持删除时补删除确认；不支持删除则移除空操作列。

## 验收
- 端口：0 不显示；http:80/https:443 不显示端口；其他端口显示。
- 时间：同区间不黄；改区间黄；按钮完整年份+秒。
- 密钥：行内单测、多选批量、行高固定。
- 变换：中文操作、JSON 往返、空行忽略、空条件前端拦截、样例 diff。
- 模型：无默认思考档、dirty 零位移、策略 hover。
- 价目：表格/JSON 切换、校验失败不提交、操作列可用。
- 现有 pytest、npm test、typecheck、lint、build、bundle、UI/semantic/terminology 门禁通过。
